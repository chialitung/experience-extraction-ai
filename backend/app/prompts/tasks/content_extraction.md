## 任务：实时结构化萃取

### 输入
本轮专家回答内容：{{expert_answer}}

### 当前已结构化信息
{{existing_structure}}

### 当前流程阶段
{{current_step}}

### 指令
请从本轮专家回答中提取以下结构化信息，并与已有信息合并：

1. **关键动作/步骤**：专家描述的具体操作步骤（按顺序）
2. **决策原则/心法**：背后的思考逻辑或判断标准
3. **辅助工具/话术原型**：使用的工具、表单、话术
4. **潜在风险/易忽略点**：提到的易错点、困难点

注意：
- 只提取本轮回答中的新信息
- 与已有信息合并时，避免重复
- 对模糊信息进行标记，但不臆测

    "steps": [
      {
        "order": 1,
        "title": "步骤标题",
        "description": "步骤描述",

      }
    ],

    "tools": [],
    "risks": []
  },
  "new_insights": ["新发现的关键洞察"],
  "gaps_remaining": ["仍需澄清的信息缺口"],

}
